# Mall Customer Unsupervised Clustering Project

## Overview
This project performs customer segmentation using K-Means clustering on mall customer data.  
It groups customers based on Age, Annual Income, and Spending Score.

## Models Used
- K-Means Clustering

## Project Structure
- `src/`: modularized Python files
- `data/`: dataset
- `models/`: saved trained models
- `app.py`: Streamlit app

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Train the model:
   python main.py

3. Run the Streamlit app:
   streamlit run app.py
